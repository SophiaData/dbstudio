## 验证范围

本轮使用实际 Vue 组件脚本、工作台和参数模型，后端边界替换为纯内存合成实现；不连接真实数据库，不访问真实配置、凭据或系统剪贴板。结果表格回归使用无 DOM 的 Vue 渲染器实际挂载/卸载组件，覆盖生命周期；它不渲染可见模板，不是已安装 App 或真实驱动验收。导出来源切换另以组件的实际事件表达式做三个状态对照。

修复只进入当前源码，未覆盖 v0.8.1 tag 或已公开安装包。发布包仍对应原提交。

## 代码与永久回归

- [结果表格](../../../../apps/desktop/src/components/ResultGrid.vue)：请求代次与 tab/page/result/generation/cursor、失效和卸载状态共同决定编辑响应是否仍有效；迟到错误也不能覆盖当前编辑错误。进入新增表单会使旧读取失效。新增操作仅返回 true 才关闭，取消或异常保留输入、勾选列和 NULL 状态。
- [工作台](../../../../apps/desktop/src/workbench.ts)：SQL 错误后尽力同步捕获的原连接事务，二次同步失败保留原错误；取消提示依据后端 bool；新增显式返回 bool；应用修改时使用原 offset 重查新数据，目标页失败后仍能从正确位置重试。
- [传输面板](../../../../apps/desktop/src/components/TransferDialog.vue)：仅在自动从 SQL INSERT 切成 CSV 时清空目标路径。
- [SQL 工作流回归](../../../../apps/desktop/tests/sql-workflow-regressions.mjs)：11 个用例，修复前 5 通过 / 6 失败，修复后 11 通过 / 0 失败。
- [结果表格回归](../../../../apps/desktop/tests/grid-workflow-regressions.mjs)：最终 17 个用例通过。初始 14 个用例修复前 2 通过 / 12 失败；随后补充的三个正反对照也通过，不伪称这三个另有修复前红色证据。

两个新增脚本不依赖既有 backups、预编译 dist 或数据库；每次使用新的临时证据目录并保留。已接入[包脚本表](../../../../package.json)的 `test:native-ui-models`，默认 `verify` 会调用同一检查入口。
