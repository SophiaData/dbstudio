# MySQL 对标任务覆盖映射

日期：2026-11-16。本文把 [对标契约](acceptance-contract.md) 的 M01–M23 与本仓库当前实际证据对齐，回答"每个用户任务现在到哪一步"，而不是统计测试数量。

用例编号、状态词和证据等级沿用契约定义，不另建一套编号。

## 证据等级

从低到高，每条结论只能宣称它实际达到的层级：

| 等级 | 含义 |
|---|---|
| L0 静态 | 只有源码实现存在 |
| L1 单元 | Rust/前端单元测试，无数据库、无界面 |
| L2 合成 DOM | 已渲染控件上的合成事件，不代表 OS 真实输入 |
| L3 真实驱动 | 原生驱动连真实数据库，不经过界面 |
| L4 真实 Tauri + 数据库 | 真实应用窗口操作 + 真实数据库 + 独立连接回读 |
| L5 参考实测 | 同任务在 dbx 上亲自操作并记录 |
| L6 安装包 | 正式候选产物上的同源验证 |

L2、L3 不能替代 L4；L1 不能替代任何真实链路；历史运行报告不因时间推移自动升级。

## 本轮清理造成的验证缺口

以下项目的自动化验证在 2026-11-16 的 legacy runtime 清理中一并移除。对应产品能力仍然存在，因此这些行属于**验证降级**，不是能力移除，也不能记作通过：

| 任务 | 失去的覆盖 | 现状 |
|---|---|---|
| M16 | CSV 导入向导 GUI 套件 | 只剩 node 级导入校验 |
| M17 | 传输任务逐段回归 | 保留导出向导与完整性检查 |
| M04 / M10 / M11 | 语句执行、编辑、DDL 的驱动级 e2e | 由 Rust 单测与真库集成测试承担 |
| M01 | 连接生命周期 e2e | 由真实验收记录与 Rust 集成测试承担 |

这些缺口需要在后续按新分层补回，而不是靠旧运行记录顶替。

## 与验收标准的关系

[Issue #15](https://github.com/SophiaData/dbstudio/issues/15) 的五条验收标准当前进展：

1. **可复现**：满足。五个场景的 RED/GREEN 演示覆盖 L1–L4，含真实 Tauri 窗口与真实 MySQL，见下节。
2. **可比较**：部分满足。已在 dbx v0.6.71 上实测 M01、M03、M04、M07、M15 五个任务的步骤与观察，见[实测记录](dbx-mysql-reference-runs.md)；其余 18 个任务仍为"参考未实测"。
3. **可维护**：部分。本文建立了统一 case 定义与覆盖状态；报告结构未统一。
4. **可信 CI**：部分。legacy 通道已从默认门禁移除；三层（node/gui/external）边界清楚，但 skip 与失败归因未成文。
5. **可信结论**：部分。本文可按任务回答"到哪一步"，但无 dbx 对照结论。

## RED/GREEN 判别力演示

2026-11-16 对五个场景做了"注入缺陷 → 观察变红 → 恢复 → 变绿"的验证，覆盖 L1 到 L4 四层。

| 场景 | 证据层 | 注入的缺陷 | RED 表现 | GREEN |
|---|---|---|---|---|
| 字符串字面量转义 | L1 | 去掉反斜杠转义，只保留引号转义 | 得到 `'a\\'b'`，期望 `'a\\\'b'`，引号会被提前闭合 | 9 项通过 |
| 大整数精度 | L1 | 去掉 2^53 越界降级 | `Int(9007199254740992)` 未保留为文本 | 通过 |
| 节点 id 解析 | L2 | 忽略转义直接 `indexOf('.')` | `全部转义时没有分隔符` 失败：实际 2，期望 -1 | 21 项通过 |
| 对象搜索 LIKE 转义 | L3 | 不再转义 `%` 与 `_` | 真库返回 `zqesc8588_100` 与 `zqesc85887100`，`_` 被当通配符 | 3 项通过 |
| 血缘分档展示 | L4 | 条目一律渲染为「确定」 | 真实 UI 出现自相矛盾：计数显示「确定 0 · 可能 1」，条目却标「确定」 | 恢复后重新显示「可能」并提示需人工确认 |

前三项变红来自断言而非编译失败；第四项在真实 MySQL 上产生错误行，由真库断言抓住；第五项在真实 Tauri 窗口中由可见文本抓住，可排除"合成数据自证"和"只测了函数"两种误判。

L4 场景的做法：真实窗口连接 MySQL，树中选中表，血缘页签读取共享列，只存在同名列证据时应显示「可能」；把条目标签写死为「确定」后 UI 自我矛盾，恢复后一致。该演示未涉及独立连接回读，因为观察对象是界面文本而非数据库状态——涉及数据写入的场景需要独立回读，本轮未做。
